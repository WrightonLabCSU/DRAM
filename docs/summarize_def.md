# SUMMARIZE

After genes have been annotated, users can SUMMARIZE this information by metabolic function (**Topic**) and within research area (**Ecosystem**). While the ANNOTATE output contains all annotations from all databases (and all the annotations in those databases), the SUMMERIZE provides the counts for the expertly curated and refined list of genes in five user-friendly Microsoft Excel workbooks for each user-specified Ecosystem (ecosystem_summary.xlsx) and across all Topics (energy_acquisition_bioenergetics_summary.xlsx, assimilation_and_cofactor_metabolism_summary.xlsx, cellular_machinery_summary.xlsx, environmental_interaction_adaptation.xlsx). All information on these sheets is contained in a tab-delimited file (summarized_genomes.tsv) that can be easily parsed in R or Python. 

SUMMARIZE can also be used to assign **Traits** to each genome. Traits are genome-level broad, metabolic function ascribed to each MAG based on the presence of curated gene sets.
