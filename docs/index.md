# DRAM2 Documentation

Distilled and Refined Annotations of Metabolism

DRAM2 annotates microbial genomes, metagenome-assembled genomes, assemblies, and predicted genes, then organizes those annotations into interpretable metabolic summaries, organism-level traits, and interactive visualizations.

DRAM1 publication is available at [Nucleic Acids Research](https://academic.oup.com/nar/article/48/16/8883/5884738), with DRAM2 soon to be released on bioarchive.

Source code is available on [GitHub](https://github.com/BortonWrightonLabs/DRAM).

See links to the left for Installation and Quick Start instructions.

Bugs reports and feature requests can be submitted through [GitHub](https://github.com/BortonWrightonLabs/DRAM).
